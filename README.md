🚀 Astronomy Quiz
About the Project
Astronomy Quiz is a fun, text-based interactive game written in Python. It tests your knowledge of the cosmos, covering topics ranging from the planets in our solar system and the stages of stellar evolution, to historical space exploration missions like Apollo 11.

How it Works
When you run the program, you are greeted and asked if you'd like to play. If you type yes, your cosmic journey begins! The quiz presents a series of 13 trivia questions. After each answer, the program instantly evaluates your input and tells you whether you are correct or incorrect.

Features

~ Interactive Gameplay: Uses Python's built-in input capabilities to create a dialogue with the player.

~ Instant Feedback: Evaluates answers in real-time using conditional logic (if/else).

~ Educational: Contains a wide variety of questions regarding planetary science, astrophysics, and astronomy history.

How to Play

~ Make sure you have Python installed on your system.

~ Download the Python file and run it in your terminal or IDE.

~ Answer the questions as they appear!

Note: The game is currently case-sensitive. Make sure to capitalize proper nouns (e.g., type Venus instead of venus).

Technologies Used

~ Python 3
